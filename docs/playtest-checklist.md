# 직접 플레이 체크리스트

자동 확인(헤드리스 스모크 테스트, 헤드리스 크롬)으로는 못 보는 것만 모았다.
기기마다 한 번씩 돌리고, 안 되는 항목은 기기·브라우저 이름과 함께 적어 둔다.

준비: `build/web`을 로컬 서버로 띄운다(README 또는 아래 "서버" 참고).
처음부터 다시 하려면 브라우저 사이트 데이터(저장)를 지우거나 시크릿 창을 쓴다.

## 1. 코어 루프 1바퀴 (PC 크롬에서 먼저)

| # | 할 일 | 확인할 것 |
| --- | --- | --- |
| 1 | 타이틀에서 아무 곳이나 클릭 | "새로 출근하기" 버튼만 나타나고, 같은 클릭으로 다음 화면으로 넘어가지 **않는다** |
| 2 | "새로 출근하기" | 출입증 발급 화면. 조이스틱·A/B 버튼이 **안 보인다**(PC) |
| 3 | 이름 칸 클릭 후 한글 입력(윈도우 한글 IME) | 조합 중인 글자도 보이고 확정 후 그대로 남는다. 8자에서 멈춘다 |
| 4 | 헤어·머리색·옷 색 ◀ ▶ | 미리보기가 바뀌고 4방향으로 돈다 |
| 5 | 이름을 비우고 "출근하기" | "이름을 입력해 주세요." 알림, 넘어가지 않음 |
| 6 | 이름 넣고 "출근하기" | 청사 로비. 0.6초 뒤 달이 인트로, 조작 안내가 **키보드용**(방향키/Space/Esc/Q) |
| 7 | Space로 대화 넘기기 | 글자가 찍히는 중에 누르면 한 번에 다 나오고, 다시 누르면 다음 줄 |
| 8 | 방향키 두 개를 동시에 누르기 | 대각선으로 가지 않고 나중에 누른 방향으로만 간다 |
| 9 | 위층 사무실 김 팀장(머리 위 !)에게 Space | 인사 → 첫 업무(교실 책상 30개) → 나르미 조달 상식 |
| 10 | 사무실 왼쪽 아래 책상 줄의 PC(파란 화면이 있는 책상) 바로 아래에서 위를 보고 Space | 업체 3곳 정보 → 선택지. "나중에 고르기"도 동작 |
| 11 | 튼튼가구 선택 | "튼튼가구와 계약했다!" → 목표가 "주차장 납품 차량으로 출발하기" |
| 12 | 오른쪽 아래 주차장 차량 앞에서 Space → "출발!" | 운전 미니게임. 3·2·1 카운트다운 |
| 13 | ← → 로 장애물 피하기, Q(에너지바 있을 때) | 차선이 바뀌고 부딪히면 화물 상태가 준다. 약 45초 뒤 "도착!" |
| 14 | 학교 도착 | "한빛초등학교에 도착!" 알림, 행정실 박 실장 머리 위 ! |
| 15 | 박 실장에게 Space | 검수 결과 [우수/보통/미흡] = 품질 × 화물 상태 |
| 16 | 아래쪽 현관(빨간 바닥)으로 나가기 | 청사 주차장으로 돌아오고 "팀장님께 보고하러 가요" 알림, 피로도 +7 |
| 17 | 팀장에게 보고 | 예산 절약액, 평판, 경험치 보상 → 자동 저장 알림. HUD 숫자가 바뀐다 |
| 18 | 같은 방법으로 2·3번째 업무 | 아이템 없이 3번째 업무를 하면 복귀 직후 피로도 100 → 나르미가 강제 퇴근, 2일차 |
| 19 | 2일차에 팀장에게 남은 보고 | 정상 보상. 하루 3건 뒤 팀장에게 "퇴근하기" 선택 → 다음 날, 일당 들어옴 |

참고 수치(1번째 업무, 튼튼가구): 예산 600 - 가격 560 = 40만원 절약.
품질 92 × 화물 상태가 80 이상이면 우수(화물 87% 이상), 55 이상이면 보통.

## 2. 메뉴·아이템·저장

- [ ] Esc → 메뉴 → 아이템: 처음 받은 커피 1잔 사용, 피로도 -15
- [ ] 구내식당(사무실 오른쪽 방)의 자판기·식권 발매기에서 구입, 돈이 모자라면 "돈이 부족해요."
- [ ] Q로 퀵 아이템 사용
- [ ] 메뉴 → 저장하기 → 새로고침 → "이어서 출근하기"로 같은 상태(예산, 진행 중 업무)
- [ ] 메뉴 → 타이틀로 → 확인 창 → 타이틀

## 3. 휴대폰 (안드로이드 크롬, 아이폰 사파리 각각)

- [ ] 첫 로딩 시간(와이파이). 너무 길면 기록
- [ ] 가로 화면으로 돌렸을 때 화면이 꽉 차고 글자가 깨지지 않는다(한글 네모 없음)
- [ ] 타이틀 탭 → 버튼만 나타남(바로 넘어가지 않음). 안드로이드는 전체화면 전환
      (아이폰 사파리는 전체화면 API가 없어서 주소창이 남는 게 정상)
- [ ] 이름 칸 탭 → 브라우저 입력 창(prompt)에 한글 입력 → 이름 칸에 반영
- [ ] 조이스틱(화면 왼쪽 아무 데나 누르고 끌기)으로 4방향 이동, 손을 떼면 멈춤
- [ ] A 버튼으로 말 걸기, 대화창 탭으로 넘기기, 선택지 버튼 탭
- [ ] B 버튼으로 메뉴, 노란 버튼으로 퀵 아이템
- [ ] 인트로 조작 안내가 **터치용**(화면 왼쪽 끌기 / A / B)
- [ ] 운전: 화면 왼쪽·오른쪽 탭으로 차선 변경, 오른쪽 위 탭으로 에너지바
- [ ] 노치 쪽 HUD·버튼이 가려지지 않는지(가려지면 P1 노치 여백 작업에 기록)
- [ ] 홈으로 나갔다 돌아왔을 때 멈추거나 입력이 고장나지 않는지
- [ ] 저장 후 브라우저를 완전히 닫았다 열어도 "이어서 출근하기"가 보이는지

## 서버

```bash
# 프로젝트 폴더에서 (Windows는 python, macOS는 python3)
python -m http.server 8000 -d build/web
```

- PC: http://localhost:8000
- 휴대폰: PC와 같은 와이파이에서 http://<PC IP>:8000 (IP는 `ipconfig`의 IPv4 주소)
- 처음 실행할 때 Windows 방화벽 창이 뜨면 "개인 네트워크" 허용. 휴대폰에서 안 열리면 방화벽부터 확인
- 빌드는 단일 스레드라 COOP/COEP 헤더나 https가 필요 없다
