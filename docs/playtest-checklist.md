# 직접 플레이 체크리스트

자동 확인(헤드리스 스모크 테스트, 헤드리스 크롬)으로는 못 보는 것만 모았다.
기기마다 한 번씩 돌리고, 안 되는 항목은 기기·브라우저 이름과 함께 적어 둔다.
재미 관련 항목(★)은 "됐다/안 됐다"보다 느낀 점을 한 줄씩 적는다. 11/18 밸런스 조정에 쓴다.

준비: PC는 `build/jodal_rookie.html`을 더블클릭하면 된다(`python tools/make_single_html.py`로 생성).
휴대폰은 `build/web`을 로컬 서버로 띄운다(아래 "서버").
처음부터 다시 하려면 브라우저 사이트 데이터(저장)를 지우거나 시크릿 창을 쓴다.

## 1. 하루 한 바퀴 (PC 크롬에서 먼저)

| # | 할 일 | 확인할 것 |
| --- | --- | --- |
| 1 | 타이틀 | 나르미·팀장·달이가 움직인다. 아무 곳이나 클릭하면 버튼만 나타나고 바로 넘어가지 **않는다** |
| 2 | "새로 출근하기" → 출입증 발급 | 조이스틱·A/B 버튼이 **안 보인다**(PC). 한글 이름 입력(윈도우 IME), 헤어·머리색·옷 색 |
| 3 | "출근 준비 끝!" | **집**에서 시작. 알람 대사, 조작 안내가 **키보드용**. 방이 화면을 꽉 채운다(2배) |
| 4 | 냉장고(오른쪽 위 흰 상자) 조사 | 에너지바 +1 팝업. 한 번 더 조사하면 "텅 비었어요" |
| 5 | 옷장 조사 → 갈아입기 | 옷장 화면에 현재 외형이 그대로, "이대로 할게요" → 집 옷장 앞으로 돌아옴 |
| 6 | 노란 ▼ 화살표 따라 현관(빨간 문)으로 | 청사 로비, "1일차 09:00", 달이 인트로 |
| 7 | 화살표 따라 위층 김 팀장 | 화면 밖이면 가장자리에 ▲▶ 화살표. 첫 업무(교실 책상 30개, 기준 60점) |
| 8 | 내 자리 PC(팀장 책상 아래 파란 화면) | 예산·검수 기준·업체 3곳. 선택지에 가격·품질이 같이 보인다 |
| 9 | ★ 업체 고르기 | "기준을 넘는 가장 싼 업체"를 고민하게 되는지 |
| 10 | 주차장 차 → 출발 | 운전 25초. 별을 먹으면 지갑 +500원, 빨간 공구상자는 화물 +10 |
| 11 | ★ 운전 | 너무 쉽거나 어렵지 않은지, 25초가 적당한지 |
| 12 | 학교 행정실 박 실장 | 검수 결과 [우수/보통/미흡] 점수와 기준이 같이 나온다 |
| 13 | 아래 현관 → 청사 복귀 → 팀장 보고 | 예산·평판 팝업이 캐릭터 근처에 떠오르고 상단 숫자가 올라간다(카운트업) |
| 14 | 하단 [성장] | 팀 예산으로 차량 정비·휴게실 소파·업체 분석 노트 구입. 분석 노트 산 뒤 PC에 [분석] 줄 |
| 15 | 2·3번째 업무 | 업무 종류가 바뀐다. 가끔 [긴급](보상 1.5배), [특가], 실장 추가 부탁 선택지 |
| 16 | 아이템 없이 3건 | 세 번째 업무 즈음 피로 100 → 나르미가 강제 퇴근 → 집에서 저녁 정산 |
| 17 | 하루 3건 완료 후 1층 현관 | 퇴근 → 집 저녁 정산. 3건 전에 현관에 가면 "아직 근무 시간" 알림만 |
| 18 | 침대에서 잠 | 다음 날 아침 07:30, 일당 입금 알림. 저녁에 현관으로 나가려 하면 막힌다 |
| 19 | ★ 전체 | 하루가 몇 분 걸리는지, 어디서 지루한지 |

참고 수치: 검수 점수 = 업체 품질 × 화물 상태. 기준 이상이면 보통, 기준 +15 이상이면 우수.
1번째 업무에서 바른공방(품질 78)은 화물 77% 이상이면 통과, 97% 이상이면 우수.

## 2. 메뉴·아이템·저장

- [ ] 하단 바 [업무]: 현재 업무, 기준, 계약 업체, 화물 상태
- [ ] 하단 바 [가방] 또는 Esc → 가방: 커피·국밥 사용, 피로도 감소
- [ ] 구내식당(사무실 오른쪽)의 자판기·식권 발매기에서 구입, 돈이 모자라면 "돈이 부족해요."
- [ ] Q로 퀵 아이템, 운전 중 Q로 에너지바(졸음 방지)
- [ ] 하단 바 [저장] → 새로고침 → "이어서 출근하기"로 같은 맵·상태(예산, 업그레이드, 진행 중 업무)
- [ ] Esc → 타이틀로 → 확인 창 → 타이틀

## 3. 휴대폰 (안드로이드 크롬, 아이폰 사파리 각각)

- [ ] 첫 로딩 시간(와이파이). 너무 길면 기록
- [ ] 가로 화면에서 화면이 꽉 차고 한글이 깨지지 않는다
- [ ] 타이틀 탭 → 버튼만 나타남. 안드로이드는 전체화면 전환
      (아이폰 사파리는 전체화면 API가 없어서 주소창이 남는 게 정상)
- [ ] 이름 칸 탭 → 브라우저 입력 창(prompt)에 한글 입력 → 이름 칸에 반영
- [ ] 조이스틱(화면 왼쪽 누르고 끌기) 4방향 이동. **하단 메뉴 바를 눌러도 조이스틱이 생기지 않는다**
- [ ] A 버튼 말 걸기, 대화창 탭 넘기기, 선택지 탭. B 메뉴, 노란 버튼 퀵 아이템
- [ ] 하단 메뉴 바 버튼이 조이스틱·A/B 버튼과 겹치지 않는다
- [ ] 인트로 조작 안내가 **터치용**
- [ ] 운전: 화면 왼쪽·오른쪽 탭으로 차선 변경, 오른쪽 위 탭으로 에너지바
- [ ] 노치 쪽 HUD·버튼이 가려지지 않는지(가려지면 P1 노치 여백 작업에 기록)
- [ ] 홈으로 나갔다 돌아왔을 때 멈추거나 입력이 고장 나지 않는지
- [ ] 저장 후 브라우저를 완전히 닫았다 열어도 "이어서 출근하기"가 보이는지

## 서버

```bash
# 프로젝트 폴더에서 (Windows는 python, macOS는 python3)
python -m http.server 8000 -d build/web
```

- PC: http://localhost:8000
- 휴대폰: PC와 같은 와이파이에서 http://<PC IP>:8000 (IP는 `ipconfig`의 IPv4 주소)
- 처음 실행할 때 Windows 방화벽 창이 뜨면 "개인 네트워크" 허용. 휴대폰에서 안 열리면 방화벽부터 확인
- 빌드는 단일 스레드라 COOP/COEP 헤더나 https가 필요 없다
