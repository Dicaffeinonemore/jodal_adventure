# 기획 요약과 우선순위

원본 기획서: "(가제) 출근! 조달청 신입 — 게임 기획서" (Claude 문서). 이 파일은 작업용 요약이다.
상태 칸은 작업하면서 갱신한다: `뼈대`(코드 있음, Godot 미검증) / `완료`(실행 확인) / `-`(미착수).

## 우선순위 규칙

| 등급 | 정의 | 완료 목표 |
| --- | --- | --- |
| P0 필수 | 빠지면 제출이 안 되거나 게임 루프가 끊김 | 11/19(목) 밤 |
| P1 권장 | 점수를 올리지만 없어도 게임은 완결됨 | 11/20(금) 밤, 기능 동결 |
| P2 여유 | 볼륨·완성도 확장 | 남는 시간에만 |
| 보류 | 공모전 이후 | - |

- P0가 끝나기 전에는 P1에 손대지 않는다.
- 등급을 올릴 때마다 직전 웹 빌드를 백업한다.
- 일정이 밀리면 늦게 끝내지 말고 범위를 줄인다. 컷 순서: P2 전부 -> P1 사운드·저장 -> P1 품질 검사 미니게임 -> P1 컨디션. P0는 줄이더라도 빼지 않는다.

## 심사 기준 (총 100점)

주제적합성 20 · 활용도 20 · 완성도 15 · 대중성 15 · 작품성 15 · 독창성 15.
조달 업무를 전달하는 요소(코어 루프, 나르미의 정책 설명)는 전부 P0다.
